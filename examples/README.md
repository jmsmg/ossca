## 읽을 때 알아둘 것

- 이 기록들은 **AI 코딩 에이전트(Claude Code)와 함께 작업하면서 에이전트가 작업 노트로 쓴 것**이다. 문장 속 "사용자"는 멘티 본인, 1인칭("내가", "우리")은 에이전트 또는 둘을 함께 가리킨다.
  "(등록은 사용자)", "사용자 지시 시에만" 같은 표기는 *원격 공개는 사람이 직접 한다*는 규칙의 흔적이다
- 개인 정보는 걷어냈다 — 멘티·멘토의 이름과 이메일, 홈 디렉토리 경로, GitHub 아이디. 리뷰어는 공개 Gerrit 핸들(`smcgruer@` 등)로만 남겼다. 모두 공개 CL에 그대로 있는 정보다
- 경로는 `$OSSCA`, `$CONTRIBUTIONS_DIR` 등 `config.env` 변수 표기로 바꿨다
- crbug · CL · PR 번호는 전부 공개된 실제 번호라 링크를 따라가면 원문(리뷰 코멘트 포함)을 볼 수 있다
- 러너 스크립트는 당시 형태 그대로다 (`~/chromium/src` 하드코딩). 새 작업은 `steps/4-build-and-test/scripts/run.sh`를 쓴다.
  `mutation_test_quota.sh`(변이 내용을 하드코딩한 원본)와 `mutate_quota_commit.py`(범용 `mutation_test.sh`에 넘기는 변이 스크립트 형태)를 비교해 보면 된다
