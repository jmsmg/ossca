## 내용

`PaymentManifestDownloader`가 HTTP `Link` 헤더에서 `rel="payment-method-manifest"`를
찾을 때 rel 값을 대소문자 구분해서 비교함. HTTP 헤더의 rel 토큰은 대소문자 구분이
없어야 하므로(RFC 8288), `rel="Payment-Method-Manifest"` 같은 서버 응답이 매칭에
실패함.

## 수정 계획

- 파일: `components/payments/content/utility/payment_manifest_downloader.cc` (rel 매칭, 335행 부근)
- 수정: rel 값 split 전에 `base::ToLowerASCII` 적용
- 테스트: `payment_manifest_downloader_unittest.cc`에 대소문자 섞인 rel 케이스 추가
