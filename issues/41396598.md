## 내용

`components/payments/core/currency_formatter.cc`가 구식 `icu::NumberFormat::createCurrencyInstance`로
포맷한 뒤 출력에서 통화 코드를 **문자열 치환으로 도려내는 핵**을 사용 중:
- 통화 코드를 3→2→1글자로 잘라가며 `findAndReplace("")` (취약: 다른 텍스트 오폭 가능)
- `"- " → "-"` 부호 보정 (2018년 crbug 850334의 "temporary" 워크어라운드가 그대로 잔존)
- 앞뒤 유니코드 공백 수동 트리밍

수정: ICU 신식 `icu::number::NumberFormatter` + `UNUM_UNIT_WIDTH_HIDDEN`으로 재작성하면
기호가 처음부터 출력되지 않아 위 핵 전체 삭제 가능.

## 구현 메모

- 신 API: `icu::number::NumberFormatter::with().unit(icu::CurrencyUnit(...)).unitWidth(UNUM_UNIT_WIDTH_HIDDEN).locale(...)` → `LocalizedNumberFormatter`
- 금액은 문자열이므로 `formatDecimal(StringPiece, status)` 사용 (double 변환 금지 — 정밀도)
- `SetMaxFractionalDigits` → `.precision(icu::number::Precision::maxFraction(n))` (LocalizedNumberFormatter는 불변 스타일이라 멤버 재할당)
- 비ISO 통화 코드의 "DUM" 더미 코드 경로: HIDDEN이면 어차피 안 보이므로 단순화 가능
- 로케일별 출력이 미묘하게 달라질 수 있음 → 테스트 기대값 조정은 CL 설명에서 다룰 것
