## 올리는 법 — 코드는 그대로, 설명만 바꾼다

`git cl upload`는 **서버 설명을 재사용**하므로 로컬에서 amend해도 반영되지 않는다(5단계 GUIDE의 함정).

```bash
cd ~/chromium/src
git checkout quota-expired-notfatal-m148
git commit --amend -F - <<'EOF'
[storage] Remove expired NotFatalUntil::M148 from quota CHECKs

M148 is long past, so the argument no longer has any effect.

The enum entry is kept for now: four CHECKs outside this directory
still use M148.

Bug: none
EOF
git log -1 --format=%B | git cl description -n -
```

빌드·테스트는 다시 돌리지 않는다 — **코드가 한 글자도 안 바뀌기 때문**이다.
(「CQ 권한이 없으면 로컬이 유일한 검증」 규칙은 코드가 바뀔 때 적용된다.)

⚠️ 지금은 `unit_tests` 빌드가 `extension-prefs-drop-installtime-migration`에서 돌고 있다.
**브랜치를 옮기면 빌드가 깨진다.** 빌드 끝난 뒤에 하거나, 설명만 바꾸는 것이므로
`git cl description` 쪽은 브랜치 체크아웃이 필요하다 → **빌드 완료 후**에 한다.
